## Decisions Made

- **`realtime.fixtures.ts` imports `feedElapsedMs` from `src/modules/ingest/state/clock.ts`** — a pure, DI-free, I/O-free helper. The plan's zero-ingest-imports isolation rule and its acceptance-criteria grep are both scoped to `src/modules/realtime/`; this fixture file lives outside that directory, reuses the same primitive the real ingest code uses (no reverse coupling), and is deleted alongside the realtime module wholesale in Phase 5 regardless.
- **`MatchClockDto.period_started_feed_ts` returns a fixed deterministic value** (`2026-07-18T15:00:00.000Z`) since no backing `GameState` anchor exists yet — confirmed by direct inspection, not guessed. Phase 5 must add `GameState.periodStartedFeedTs`.
- **`QuestionMessageDto extends QuestionResponseDto`** (adds only `is_mock`) rather than nesting it under a `question` field, satisfying "reuse `QuestionResponseDto` as the payload type" literally.
- **`buildResolution` deterministically resolves to the `shot` rung** (falls back to the question's last option if absent) rather than always the highest or lowest, avoiding monotonous demo data while staying fully deterministic.
- **`RealtimeModule` does not call `ScheduleModule.forRoot()`** — confirmed via the installed `@nestjs/schedule` source that `IngestModule`'s existing registration is `global: true` and already exports `SchedulerRegistry` application-wide.
- **`RealtimeGateway` tracks room membership itself** (`Map<socketId, Set<room>>`) instead of reading `client.rooms` in `handleDisconnect` — verified against the installed socket.io 4.8.3 source that `leaveAll()` empties `client.rooms` before the `'disconnect'` event NestJS binds `handleDisconnect` to. This resolves the plan's flagged socket.io-timing assumption by direct source inspection rather than assumption.
- **`FakeCycleService` also registers the resolution `setTimeout` via `SchedulerRegistry.addTimeout`** (beyond what the plan's illustrative code sample showed for intervals only), so `onModuleDestroy` sweeps both `getIntervals()` and `getTimeouts()` for full belt-and-suspenders teardown coverage.
