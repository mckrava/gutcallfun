game cycle: a full `snapshot` on subscribe, a `game_event` every ~4s, a `question` every ~30s

instead of waiting for Phase 4. The event names, payload shapes, and room semantics frozen here are
what Phase 5 re-implements against the real state machine with zero UI rework (D-05).

teardown, a gateway with its own CORS configuration (D-06), and a committed `WS-CONTRACT.md` —
because Swagger structurally cannot describe socket.io events.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → socket.io handshake | The first WebSocket surface this application has ever exposed. The handshake is a separate HTTP upgrade path that `app.enableCors()` does not cover. |
| WS client → gateway message handlers | Untrusted `subscribe`/`unsubscribe` payloads reach handlers that allocate server-side timers. |
| fake-cycle timers → process lifetime | Registered intervals can outlive the application and the Jest worker. |
