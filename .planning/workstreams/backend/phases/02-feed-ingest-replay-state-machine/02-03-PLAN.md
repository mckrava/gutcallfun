<objective>
Build the source-unaware correctness core: a defensive normalizer that maps any raw PascalCase feed message to game_event columns, an idempotent same-transaction persistence path (orIgnore insert + stream_cursor flush inside a per-game mutex), and the per-game in-memory state machine that applies possession.ts/goals.ts after each persisted event and detects seq gaps. This is the persist-then-broadcast backbone every later plan and phase depends on.

Purpose: Correctness invariants that must hold before any live or replay source is wired — idempotent append-only log, cursor-never-ahead-of-events recovery safety, per-game serial processing, and self-healing gap detection.
Output: event-ingest.service.processEvent(gameId, rawEvent) — the single entry point live SSE (Plan 05) and replay (Plan 06) both call.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| feed message → normalizer | Untrusted external JSON (even a trusted vendor's feed) crosses into persistence and state |
| pipeline → game_event log | Append-only sacred log; the boundary where idempotency + immutability must hold |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-03-01 | Denial of Service | normalizer on malformed/hostile JSON | high | mitigate | try/catch defensive parse; store raw + ignore unknown Action/StatusId; one bad message never kills the stream (INGST-03). |
| T-02-03-02 | Tampering | append-only game_event log | high | mitigate | Insert-only via orIgnore; no UPDATE/DELETE of game_event in this pipeline; live-game immutability enforced (append-only prohibition). |
| T-02-03-03 | Repudiation / recovery-integrity | stream_cursor vs event insert | high | mitigate | Cursor UPDATE in the same transaction as the insert, never ahead of persisted seq (INGST-04 / Pitfall 4) — prevents RCVR-02 skipping an unpersisted event. |
| T-02-03-04 | Tampering | interleaved-await state corruption | medium | mitigate | Per-game async-mutex serializes processEvent (STAT-02). |
</threat_model>
