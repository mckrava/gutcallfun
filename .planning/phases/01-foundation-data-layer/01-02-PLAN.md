<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app config (ConfigService) → TypeORM connection factory | Validated env crosses into the runtime DB connection |
| ORM auto-sync engine → live schema | TypeORM's schema-sync could mutate the hand-authored schema if enabled |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Tampering/DoS | TypeORM synchronize vs hand-authored schema | high | mitigate | `synchronize: false` hard-locked in both data-source.ts and the forRootAsync factory; enabling it could silently drop the partial indexes/enums (DATA-03) |
| T-01-05 | DoS | process shutdown | medium | mitigate | `enableShutdownHooks()` ensures SIGTERM closes the TypeORM pool gracefully instead of leaking connections / timing out the grace period (DATA-04, foundation for the Phase 2 stream_cursor SIGTERM flush) |
| T-01-06 | Tampering | CLI/app connection drift | medium | mitigate | Single shared options shape consumed by both CLI (`-d src/db/data-source.ts`) and the app factory — no divergent connection settings |
</threat_model>
